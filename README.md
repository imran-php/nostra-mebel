# NOSTRA — сайт и админка

**Сайт:** https://imran-php.github.io/nostra-mebel/ (витрина)  
**Полная версия с админкой:** https://nostra-mebel.netlify.app

Сайт мебельной студии с каталогом работ, своей админкой, статистикой посещений и редактируемыми документами. Стек: HTML/CSS/JS, Netlify Functions, Netlify Blobs.


Сайт: `/` · Админка: `/admin`

## Что внутри
- `public/` — сайт (адаптирован под телефон) и админка (`public/admin/`)
- `netlify/functions/` — серверная часть: каталог, фото, статистика, админка
- Данные и фотографии хранятся в **Netlify Blobs** (встроено в Netlify, отдельная база не нужна)

## Запуск на Netlify (один раз)
1. Залейте папку в репозиторий GitHub и подключите его в Netlify
   (**Add new site → Import an existing project**), либо из этой папки выполните
   `npx netlify-cli deploy --prod`.
   ⚠️ Простое перетаскивание папки в Netlify не подходит — так не загружаются серверные функции.
2. Netlify → **Site configuration → Environment variables** → добавьте:
   - `ADMIN_PASSWORD` — пароль владельца для входа в `/admin` (не короче 8 символов)
   - `SESSION_SECRET` — любая длинная случайная строка (необязательно, но желательно)
3. Сделайте повторный деплой (**Deploys → Trigger deploy**), чтобы переменные применились.
4. Откройте `https://ваш-сайт/admin`, войдите и замените примеры своими работами.
   Пароль потом можно сменить прямо в админке (Настройки → Безопасность).

## Статистика
Считается без cookies и без сохранения IP: посетители, просмотры, звонки менеджеру/владельцу,
переходы в WhatsApp, популярные модели и категории, источники и устройства. Роботы не учитываются.

## Документы (подвал сайта)
Страницы `/docs/privacy`, `/docs/cookies`, `/docs/terms`, `/docs/requisites`.
Тексты редактируются в админке: Настройки → «Документы в подвале сайта».
Реквизиты (Настройки → «Реквизиты продавца») подставляются в документы и подвал автоматически.
